# JkaBspMap editor node

1. Enable **JKA BSP Importer** in Project > Project Settings > Plugins.
2. Add a **JkaBspMap** node with Add Node.
3. Set **Base Directory** to the game's GameData/base folder. The initial default points to this machine's Steam installation.
4. Choose **Bsp Map** from the populated dropdown. Click **Refresh Maps** after adding archives or changing their contents.
5. Click **Build Map**, then save your scene.

**Map Archive** optionally restricts the map picker to one PK3. Leave it empty to find maps across all PK3s in Base Directory. Duplicate map paths resolve to the later alphabetic archive. Texture and shader lookup uses Base Directory, even if Map Archive points elsewhere.

**Load Textures** enables the base-image shader resolver. **Curve Subdivisions** controls segments per quadratic patch span. **Map Units Per Godot Unit** defaults to 32, matching FuncGodot. **Preview Lighting** adds ambient environment and directional lighting; disable it when using your scene's own lighting.

Build replaces only direct children marked as generated by this plugin, leaving other children alone. Geometry is built off-tree first; failed builds retain the previous map. Successful builds support Godot Undo/Redo. Edits made inside generated MapGeometry will be replaced on rebuild. The status text describes the last operation and is not part of Undo/Redo history.

The generated subtree belongs to your edited scene and contains its meshes and textures. Saving keeps those resources; the game archives are not read at runtime. Binary .scn saves are more compact than .tscn for scenes with embedded image data. This first version builds synchronously, so the editor may pause for a few seconds while importing a map.

Material resolution details are stored as metadata on MapGeometry (`material_report`). Existing shader approximation, collision, submodel placement, patch-stitching and visibility limitations still apply; see TEXTURES.md and BUILDING.md. No gameplay entities or collisions are generated.

To reuse the plugin in another project, copy the entire addons/jka_bsp folder and enable it there. Update Base Directory for that machine. No FuncGodot dependency is required.
